# 자체 회원가입과 로그인

Render 배포의 회원가입 입력은 이름(1~30자), 아이디(영문·숫자·밑줄 3~24자), 비밀번호(8~128자) 세 가지입니다. 이름은 닉네임으로 사용할 수 있습니다. 아이디는 첫 글자를 영문 또는 숫자로 시작하며 앞뒤 공백을 제거하고 소문자로 저장합니다. 대소문자만 다른 아이디는 같은 계정으로 취급하고 중복 가입을 거부합니다.

로그인은 아이디와 비밀번호만 사용합니다. SNS 로그인, 이메일 확인, 이메일 및 전화번호 입력은 없습니다. 새로운 계정의 기존 DB email 열은 NULL로 유지합니다. 비밀번호는 무작위 salt를 사용하는 scrypt 해시로 저장하고 세션은 HttpOnly 쿠키로 유지합니다. 사용자 정보 응답에는 내부 UUID·아이디·이름만 포함합니다. 로그인 실패 횟수 제한과 출처 검사도 유지합니다.

기존 이메일 기반 계정의 UUID, 비밀번호 해시, 세션, 덱, 기록, 방 참여 정보는 그대로 유지합니다. 기존 이메일을 로그인 아이디로 이관하므로 아이디 입력란에 이전 이메일을 입력해 로그인할 수 있습니다. 기존 계정의 이름 기본값은 이메일의 @ 앞부분(최대 30자)입니다. 가입 이름은 공동 방 플레이어 이름에 기본 입력되며 방에서 원하는 별명을 사용할 수 있습니다.

테스트: `tests/auth.test.mjs`는 입력 검증과 실제 PostgreSQL에서 기존 계정 이관·재초기화·세션·덱 보존을 검증합니다. 서버 및 공동 방 테스트는 새 아이디 계정으로 수행합니다. `scripts/smoke-deployment.mjs`, `scripts/smoke-rooms.mjs`도 이메일 없이 가입하도록 변경했습니다.

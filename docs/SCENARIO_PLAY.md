# 시나리오와 플레이 방식

시나리오 메뉴에서 카탈로그의 `플레이 시작`을 누르면 싱글 플레이(1인) 또는 다인 플레이(2~4인)를 선택한다. 나의 모험과 플레이 기록의 새 기록 버튼도 같은 선택 화면을 사용한다.

싱글 플레이는 선택한 시나리오와 1인 인원을 플레이 기록 편집기에 전달한다. 다인 플레이는 선택한 시나리오를 방 생성 화면에 전달한다. 시나리오 메뉴의 `참여 중인 다인 플레이 · 초대 코드`에서 기존 방과 초대 참여를 관리한다.

새 초대 링크는 `#scenarios?mode=multi&join=CODE`를 사용한다. 기존 `#rooms?join=CODE` 링크는 동일한 통합 시나리오 화면으로 연결되며 초대 코드를 유지한다. 기존 기록과 방의 DB 구조 및 접근 권한은 변경하지 않는다. 비로그인 방문자는 카드 조회만 가능하다.

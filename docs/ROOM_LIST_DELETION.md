# 내가 참여한 방 삭제

방 목록의 `삭제`와 방 상세의 `내 목록에서 삭제`는 로그인 계정의 목록에서만 방을 제거한다. 공유 방, 다른 참여자, 등록한 덱 및 준비 상태는 유지된다. 방장과 참여자 모두 사용할 수 있으며 방 상태와 무관하다.

`삭제한 방 보기`에서 복원할 수 있다. 삭제 및 복원 상태는 Render PostgreSQL의 `lotr_room_members.deleted_at`에 저장된다. 기존 방은 기본적으로 목록에 표시되며, 초대 코드로 기존 방에 다시 참여하면 본인의 삭제 상태를 해제한다.

인증, 본인 계정 일치, 참여자 권한, Origin 검사를 서버에서 적용한다. 방 행을 잠근 트랜잭션으로 본인의 상태만 변경한다. 영구 삭제 API는 제공하지 않는다.

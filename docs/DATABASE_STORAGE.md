# 계정 DB 저장

덱·플레이·캠페인·보유 확장팩은 로그인 후 Render PostgreSQL API에 저장합니다. 로그인 전에는 기록을 불러오거나 저장하지 않으며 덱 생성과 플레이 기록 생성은 로그인 창으로 안내합니다. 카탈로그는 로그인 없이 열람할 수 있습니다.

DB 쓰기가 성공한 뒤에만 화면의 기록을 갱신하고 ‘저장하였습니다’를 표시합니다. 실패하면 이전 저장 상태를 유지하고 오류를 알리며 편집 창의 입력은 보존합니다. 새 기록을 localStorage에 쓰는 처리와 실패 시 저장 완료로 처리하던 동작을 제거했습니다. 새로고침 및 로그인 시 DB에서 기록을 읽습니다.

이전 버전 데이터 손실을 방지하기 위해 기존 저장 데이터를 읽는 이관 기능은 남겼습니다. 로그인 시 이전 미동기화 요청이 있으면 DB로 이관하고 기존 요청을 제거합니다. 설정의 ‘이전 기록 가져오기’는 이전 게스트 기록을 DB에 추가합니다. 이 기능들은 새 로컬 기록을 생성하지 않습니다. JSON 백업 다운로드 및 복원 기능은 계속 지원합니다.

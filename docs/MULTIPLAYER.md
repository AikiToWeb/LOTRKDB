# 공동 시나리오 방

`공동 시나리오 방` 메뉴에서 로그인한 사용자가 시나리오와 최대 인원(1~4명)을 선택해 방을 만듭니다. 초대 코드나 링크를 공유하면 다른 계정이 플레이어 이름을 입력해 참여할 수 있습니다. 방 목록과 상세는 참여자에게만 보입니다. 이메일과 덱의 비공개 메모는 공유하지 않습니다.

각 참여자는 자신의 계정에 저장된 덱을 등록하고 준비 완료를 누릅니다. 등록 당시 이름과 카드 구성의 스냅샷을 공유합니다. 원래 덱을 수정하거나 삭제해도 이미 등록한 구성은 유지되며, 새 구성을 사용하려면 대기 중 다시 등록해야 합니다. 재등록하면 준비가 취소됩니다. 서버에 아직 동기화하지 못한 덱은 등록할 수 없습니다.

방장만 시나리오를 시작·종료하거나 방을 닫을 수 있습니다. 시작에는 모든 참여자의 덱 등록과 준비가 필요합니다. 참여자 간 동일 이름의 영웅(다른 인쇄판 포함)이 중복되면 시작을 막습니다. 일반 덱의 50장 제한 등 덱 검사 결과도 표시하지만, 기본판 연습용 덱을 사용할 수 있도록 이 경고 자체로 시작을 막지는 않습니다. 진행 중에는 참여, 덱 변경, 탈퇴가 잠깁니다. 대기 중 참여자는 나갈 수 있고, 방장은 다른 참여자를 제외할 수 있습니다.

방 상태는 화면이 열려 있을 때 10초마다 갱신됩니다. 방과 참여 덱은 Render PostgreSQL에 저장되므로 서버 재시작 후에도 유지됩니다. 이 기능은 공동 시나리오 준비와 덱 공유를 지원하며, 카드 조작이나 규칙 처리를 대신하는 온라인 게임 엔진은 아닙니다. 게임의 승패와 점수는 각자 플레이 기록에 입력합니다. 무료 DB 만료 시에는 공유 방 데이터도 영향을 받습니다.

테스트: `tests/rooms.test.mjs`. 실제 PostgreSQL 테스트는 `TEST_DATABASE_URL`이 설정된 GitHub CI에서 수행합니다. 계정 격리, 본인 덱 소유권, 스냅샷, 동시 마지막 자리 참여, 준비 및 방장 권한을 검증합니다.

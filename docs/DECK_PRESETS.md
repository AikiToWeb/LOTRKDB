# 코어 덱 프리셋

모든 ‘새 덱 만들기’ 버튼은 프리셋 선택 화면을 엽니다. 선택한 덱의 영웅, 플레이어 덱 장수, 시작 위협, 전체 카드 목록을 확인하고 이름을 바꿔 바로 등록할 수 있습니다. 기존 덱을 덮어쓰지 않고 새 UUID로 저장하며, 로그인 계정의 동기화와 공동 방 덱 등록을 그대로 사용합니다. ‘빈 덱으로 시작’은 기존 덱 빌더를 엽니다.

출처: [FFG Revised Core Learn to Play](https://images-cdn.fantasyflightgames.com/filer_public/e9/2f/e92f2465-8a1e-4bfa-8293-ad0edd5e55c0/mec101_learn_to_play_eng_v11-compressed.pdf), 인쇄된 5쪽과 27쪽. 5쪽은 영역별 카드 범위 전체와 간달프 2장을 지시합니다. 개정판은 해당 영역의 플레이어 카드 15종을 각 3장씩 사용하여 47장입니다. [구판 Learn to Play](https://images-cdn.fantasyflightgames.com/filer_public/ed/c7/edc7c539-c4d4-461c-b998-17fa2451a303/learn_to_play.pdf) 6쪽은 간달프 1장을 지시하며, 카탈로그의 구판 코어 1상자 수량을 적용하여 30장입니다. 영웅은 덱 장수에서 제외하며 각 1장씩 사용합니다. 튜토리얼 구성은 화면과 덱 메모에서 일반 50장 규칙의 학습용 예외임을 설명합니다.

개정판 추천 통솔·정신, 지식·전술은 27쪽 목록과 수량을 그대로 반영한 각 50장 덱입니다. 구판 선택에서는 이 두 덱을 제공하지 않습니다. 개정판 한 상자로 양쪽 추천 덱을 함께 사용하려면 간달프가 합계 6장 필요합니다. 튜토리얼 4개를 함께 사용할 때는 간달프가 합계 8장 필요합니다. 개별 덱 카탈로그 수량과 여러 덱의 실제 카드 공유는 별도로 확인해야 합니다.

`tests/deck-presets.test.mjs`는 판본별 튜토리얼 영역·수량·영웅·간달프, 추천 덱 50장·영웅·일반 구성 검증, 저장 형식, 편집 시 원본 보존을 검증합니다.

# 로그인별 메뉴 접근

첫 화면은 카드 도서관입니다. 비로그인 방문자는 카드 검색, 목록, 이미지와 효과 상세만 이용할 수 있습니다. 메뉴에는 카드 도서관만 표시합니다. 회원가입·로그인은 항상 사용할 수 있습니다.

나의 모험·덱·시나리오·공동 방·플레이 기록·보유 확장팩·설정은 로그인 후 표시합니다. 비로그인 사용자가 해당 해시 URL로 직접 접근하면 개인 화면 대신 로그인 안내만 렌더링합니다. 로그인하면 요청한 화면을 그대로 열므로 공동 방 초대 URL의 코드도 유지됩니다. 로그인 판별 전에는 확인 화면을 표시하고 로그아웃 시 열린 개인 편집 창과 삭제 창을 닫습니다.

서버의 `/api/state`와 `/api/rooms`는 기존 세션 인증을 유지하여 브라우저 화면을 우회한 비로그인 읽기·쓰기도 401로 거부합니다. 공개 `/api/catalog`는 카드 조회용 공개 데이터이고 `/api/health`는 배포 점검에 사용합니다.
